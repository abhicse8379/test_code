## 📌 Recommended Workflow

1. Complete the assigned practical.
2. Test the webpage in a browser.
3. Verify HTML, CSS, and JavaScript functionality.
4. Commit your changes with a meaningful commit message.
5. Push your work to GitHub.

## 📖 Learning Outcomes

After completing all practicals, students will be able to:

* Design static web pages using HTML5.
* Apply CSS for responsive and attractive layouts.
* Implement JavaScript for client-side interactivity.
* Develop structured and maintainable web applications.
* Manage project versions using Git and GitHub.
* Follow industry-standard project organization practices.

---

## 📝 Best Practices

* Maintain one folder for each practical.
* Use meaningful file and folder names.
* Keep code properly indented and commented.
* Test your webpages before committing.
* Commit frequently with descriptive commit messages.
* Push your work regularly to GitHub.
